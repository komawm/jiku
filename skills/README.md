# Jiku skills

This is Jiku's internal skill directory, not a separate repository or an implemented runtime. The [Jiku configuration proposal](https://github.com/komawm/docs/blob/main/docs/JIKU_CONFIG_SPEC.md) describes approved deterministic GUI macros and their eventual promotion process.

No executable skills are supplied by this initialization. Add skills only alongside an accepted interface, capability/resource limits and validation evidence. Keep approval, provenance and runtime behavior explicit; a template must not imply it has been executed or approved.
