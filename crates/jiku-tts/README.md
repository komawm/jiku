# jiku-tts

This library-only scaffold reserves the speech/notification integration boundary. It contains no implemented runtime functions, has no executable target and is marked `publish = false`.

See the [Jiku overview](https://github.com/komawm/jiku), [crate map](https://github.com/komawm/jiku/tree/main/crates), and [canonical architecture](https://github.com/komawm/docs/blob/main/docs/JIKU_ARCHITECTURE.md). Implementation and acceptance require a separately scoped task.
