# Jiku configuration templates

[config.toml](https://github.com/komawm/jiku/blob/main/examples/config.toml) and [init.lua](https://github.com/komawm/jiku/blob/main/examples/init.lua) accompany the [configuration proposal](https://github.com/komawm/docs/blob/main/docs/JIKU_CONFIG_SPEC.md) and [architecture](https://github.com/komawm/docs/blob/main/docs/JIKU_ARCHITECTURE.md).

These imported templates are design inputs. Jiku currently has no daemon or provider implementation; names, endpoints, memory/TTS settings and policy hooks are not verified integrations. Keep real credentials and private endpoints outside tracked examples.
